08 / Frequently Answered

Engineered for scrutiny.

Recruit executes a progressive pipeline: first, hard constraint filters (location, rights to work, notice period) isolate eligible candidates. Second, high-dimensional vector similarity ranks the top 40 best fits. Finally, the LLM reads those 40 CVs in full text, generating grounded scores with cited page evidence and explicitly identified gaps.
Never contact information or direct PII. Emails, phone numbers, exact physical addresses, and social profile links are stripped via our local pre-inference filter. The model only receives anonymized professional context. Furthermore, zero agency data is ever permitted to train foundation models.
Yes. We provide automated mapping for Bullhorn, Recruit CRM, Vincere, and legacy SQL dumps. For spreadsheets, our bulk importer parses 500 records per run with continuous checkpointing, duplicate identification, and resume capabilities if network interrupts occur.
All databases and document buckets are physically pinned to AWS Frankfurt (eu-central-1). Tenant isolation is enforced via PostgreSQL Row-Level Security (RLS) at the database layer, meaning one firm’s query can never physically bridge into another agency’s records.
